03 — Method

复现方法

论文在数据中心 GPU 上端到端训练。本复现改用可在 CPU 上收敛的三步分解策略，最终系统的物理结构与论文一致。

01

可微物理链路

用 dlarray 实现可微角谱传播，梯度从传感器强度回传到 SLM 相位；SLM 区域外复数场置零（暗孔径），避免固定背景光淹没信号。

02

原型拟合

每类 5 个相位种子 + 共享衍射解码层，以逐任务流方式拟合「类均值 + 真实样本」混合目标，再冻结解码层抛光，平均 MSE 0.008。

03

场空间混合生成

类内种子做复数域随机凸组合（物理上＝多张相位图样叠加），取合成场相位再走一遍光学前向，即可无限采样新的类别样本。

04 — Quick Start

四行命令上手

已训练模型随仓库提供，无需重训即可生成结果图；完整重训见仓库 README。

bash · paper-repro-lab 
# 1. 取代码
$ git clone https://github.com/Alice-P197/paper-repro-lab.git
$ cd paper-repro-lab/reproductions/optical-generative-models/matlab

# 2. 下载数据集（约 12 MB，自动解压）
$ matlab -batch "download_data('mnist')"

# 3. 免训练直接生成 —— 读入已训练模型，输出 10 类 × 8 样本
$ matlab -batch "quickstart"

# 4.（可选）从零重训：每个数据集约 18 分钟（纯 CPU）
$ matlab -batch "setenv('OGEN_DATASET','mnist'); train_prototypes"
