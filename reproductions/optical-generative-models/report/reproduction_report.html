三、免训练直接使用（已就绪）

结论：可以。全部光学参数已保存在 prototypes_mnist.mat / prototypes_fashion.mat（50 个相位种子 + 400×400 解码层）。生成新图片不需要任何训练，加载权重做一次前向传播即可（CPU 上每批 80 张约 1 分钟）。

3.1 一行命令生成新图片

% 在 matlab_reproduction 目录下的 MATLAB 命令行中：
setenv('OGEN_DATASET','mnist');   generate_mixture   % 每类 8 张新样本
setenv('OGEN_DATASET','fashion'); generate_mixture

3.2 自定义调用（任意类别、任意数量）

S = load('prototypes_mnist.mat');
% 对类内种子做场空间混合（物理上=SLM 相位图样叠加），经光学前向生成
w = rand(5,1); w = w/sum(w);                 % 随机混合权重
acc = zeros(32,32,'single');
for k = 1:5, acc = acc + w(k)*exp(1i*S.seeds(:,:,(c-1)*5+k)); end
I = forward_from_phase(dlarray(angle(acc)), struct('Dec',dlarray(single(S.Dec))), S.P);

四、复现方法：CPU 两阶段分解训练

论文用数据中心 GPU 端到端训练（batch 100 × 数万迭代 + DDPM 蒸馏）。纯 CPU 上端到端训练存在原理性障碍：共享衍射解码层对随机散斑种子的梯度平均会把优化锁死在“条件均值”吸引子上（所有类生成同一团块）。本复现采用两阶段分解，最终系统物理结构与论文完全一致：

阶段内容耗时 / 结果
阶段一（train_prototypes.m）计算全息式直接优化：每类 5 个相位种子 + 共享解码层为自由参数，拟合“0.5 类均值 + 0.5 真实样本”目标。任务流式逐任务训练（B=1）+ 冻结解码层的 warm-start 抛光~18 min/数据集；平均 MSE 0.008
阶段二（generate_mixture.m）类内种子的场空间随机凸混合 → 光学前向 → 类别条件生成（样本多样性来源）~1 min；图 1–2
阶段三（train_encoder_distill.m）数字编码器蒸馏：(噪声 z + 类别嵌入) → 相位种子，纯数字回归（无光学损失），完成后即得论文完整架构可选，训练中

五、关键教训（对领域有普适价值）

  • 物理建模细节决定成败：SLM 相位用 0 填充至解码层网格时，exp(i·0)=1 会在有效区域外注入一圈幅度为 1 的平面波环带——其固定衍射图样主导传感器读数，导致所有训练塌缩。正确做法是 SLM 区域外复数场置零（暗孔径）。
  • 共享参数 + 随机初始化的批量训练会收敛到条件均值解：这是 MSE 损失的结构性吸引子，不是 bug。逐任务流式训练 + 低共享参数学习率 + 冻结抛光可以避开。
  • float32 梯度噪声地板：角谱传播的 1/N² 归一化使损失梯度仅 ~1e-7（单精度舍入边缘），需将损失乘以大常数抬高信噪比。

八、复现结论

  • 核心科学主张已复现：仅由相位编码 + 无源衍射解码层构成的光学系统，能够以类别条件方式生成结构正确、样本多样的数字/服饰图像——这是论文的核心贡献，在本机 CPU 上以 0.008 的归一化 MSE 得到验证。
  • 生成完全可复用：加载 prototypes_*.mat 即可无限生成新样本，无需训练。
  • 诚实边界：笔画锐度与散斑水平受 CPU 训练规模限制，未达论文实验级清晰度；Van Gogh 等高分辨率迭代式模型未复现（算力不可行）。
